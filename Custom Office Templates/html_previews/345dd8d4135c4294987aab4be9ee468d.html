១. ល្បឿនមធ្យម (vav)

គិតល្បឿនជាមធ្យម ពីចំណុច A ទៅ C (ចម្ងាយសរុប ÷ រយៈពេលសរុប)។

vav = Δx / Δt

📝 លំហាត់អនុវត្តន៍ (Worksheet)

លំហាត់ទី ១ (កម្រិតមូលដ្ឋាន៖ គណនាទីតាំង និងល្បឿនមធ្យម)
ម៉ូតូមួយផ្លាស់ទីតាមខ្សែកោង ដែលមានសមីការទីតាំងធៀបនឹងពេលវេលា៖
x(t) = 5t² + 10t + 20 (គិតជា meters និង t គិតជា seconds)

ក. គណនាទីតាំងរបស់ម៉ូតូនៅខណៈ t1 = 0 s (ចំណុច A) និង t2 = 2 s (ចំណុច B)។
ខ. គណនាល្បឿនមធ្យមរបស់ម៉ូតូ ក្នុងចន្លោះពេលពី t = 0 s ទៅ t = 2 s។
🔑 ដំណោះស្រាយ៖
ក. គណនាទីតាំង៖
• ត្រង់ t1 = 0 s ៖ x(0) = 5(0)² + 10(0) + 20 = 20 m
• ត្រង់ t2 = 2 s ៖ x(2) = 5(2)² + 10(2) + 20 = 20 + 20 + 20 = 60 m

ខ. គណនាល្បឿនមធ្យម (vav)៖
vav = Δx / Δt = (x(2) - x(0)) / (2 - 0) = (60 - 20) / 2 = 40 / 2 = 20 m/s
លំហាត់ទី ២ (កម្រិតមធ្យម៖ គណនាល្បឿនខណៈ និងប្រៀបធៀប)
ដោយប្រើប្រាស់សមីការទីតាំងដដែល x(t) = 5t² + 10t + 20 ៖

ក. រកកន្សោមល្បឿនខណៈ v(t) របស់ម៉ូតូតាមរយៈដេរីវេនៃទីតាំង v(t) = x'(t)។
ខ. គណនាល្បឿនខណៈត្រង់ចំណុច B (នៅខណៈពេល t = 2 s) រួចបំបែកតម្លៃនេះជា km/h។
គ. ធ្វើការប្រៀបធៀបតម្លៃល្បឿនមធ្យម (រកបានក្នុងលំហាត់ទី១) និងល្បឿនខណៈត្រង់ចំណុច B។
🔑 ដំណោះស្រាយ៖
ក. រកកន្សោមល្បឿនខណៈ v(t)៖
v(t) = x'(t) = d/dt (5t² + 10t + 20) = 10t + 10 (m/s)

ខ. ល្បឿនខណៈត្រង់ចំណុច B (t = 2 s)៖
v(2) = 10(2) + 10 = 30 m/s
• បំបែកជា km/h ៖ 30 × 3.6 = 108 km/h

គ. ការប្រៀបធៀប៖
• ល្បឿនមធ្យម vav = 20 m/s (ជាល្បឿនមធ្យមសរុបក្នុងចន្លោះ 0s ទៅ 2s)។
• ល្បឿនខណៈ vB = 30 m/s (ជាល្បឿនពិតប្រាកដចំខណៈ t = 2s)។ តម្លៃទាំងពីរនេះមិនស្មើគ្នាទេ ព្រោះម៉ូតូមានចលនាស្ទុះ (ល្បឿនកើនឡើងរហូត)។
លំហាត់ទី ៣ (កម្រិតអនុវត្ត៖ រកមេគុណប្រាប់ទិស និងពេលវេលា)
ម៉ូតូផ្លាស់ទីលើផ្លូវត្រង់មួយដោយសមីការទីតាំង x(t) = 2t³ - 3t² + 40 (m និង s)។

ក. គណនាមេគុណប្រាប់ទិស (Slope) នៃបន្ទាត់ប៉ះទៅនឹងខ្សែកោងទីតាំង x(t) នៅខណៈពេល t = 3 s។ តើមេគុណប្រាប់ទិសនេះតំណាងឱ្យអ្វី?
ខ. តើនៅខណៈពេល t ប៉ុន្មាន ទើបម៉ូតូមានល្បឿនខណៈស្មើនឹង 36 m/s?
🔑 ដំណោះស្រាយ៖
ក. មេគុណប្រាប់ទិសនៃបន្ទាត់ប៉ះត្រង់ t = 3 s៖
• កន្សោមល្បឿនខណៈ (មេគុណប្រាប់ទិស) ៖ k = x'(t) = 6t² - 6t
• ត្រង់ t = 3 s ៖ k = 6(3)² - 6(3) = 54 - 18 = 36
សន្និដ្ឋាន៖ មេគុណប្រាប់ទិសនេះតំណាងឱ្យ ល្បឿនខណៈ របស់ម៉ូតូនៅខណៈពេល t = 3 s ដែលស្មើនឹង 36 m/s។

ខ. រកខណៈពេល t ពេលល្បឿនខណៈ v = 36 m/s៖
6t² - 6t = 36 ➔ 6t² - 6t - 36 = 0 ➔ t² - t - 6 = 0
(t - 3)(t + 2) = 0 ➔ t = 3 s (ជ្រើសយក t > 0)
ដូចនេះ៖ នៅខណៈពេល t = 3 s ម៉ូតូមានល្បឿនខណៈស្មើនឹង 36 m/s។
